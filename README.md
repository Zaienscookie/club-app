
## 项目简介
社团网盘 Android WebView 壳，加载 https://st.zain-dev.top

## 功能特性
- 深色主题
- 全屏沉浸
- 返回键回退网页历史

## 使用说明
安装 APK 后打开即进入社团网盘，需登录账号

## 构建指南
需要 Android SDK 34 + JDK 17，gradle assembleDebug

## 版本历史
v0.1 系列持续迭代，WebView 基础功能

## 常见问题
Q: 打不开？A: 检查网络/域名可达性

## 界面说明
底部状态栏深色，WebView 全屏显示

## 安全说明
仅加载 HTTPS 站点，不启用 file 访问

## 性能优化
启用缓存模式，减少重复加载
